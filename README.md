# Aulas CSS

Repositório com exercícios práticos de CSS3, desenvolvidos durante um curso em vídeo. O conteúdo está organizado em cinco níveis de progressão, do básico ao avançado, cada um dividido em aulas numeradas que abordam um conceito específico da linguagem.

## Tecnologias

- HTML5
- CSS3

## Estrutura do repositório

```
Aulas CSS/
├── Iniciante/
├── Intermediário/
├── Avançado/
├── FlexBox/
└── Grid/
```

### Iniciante

Fundamentos do CSS: sintaxe, seletores básicos e propriedades de caixa.

| Aula | Tema |
|---|---|
| Aula Introdutória 01 | Primeiro contato com CSS |
| Aula Introdutória 02 | Estilização de um site com múltiplas páginas (início, produtos, contato) |
| Aula 01 (Div / Span) | Elementos de bloco (`<div>`) e inline (`<span>`) |
| Aula 02 (Cores / Fontes) | Propriedades de cor e tipografia |
| Aula 03 (Caixas) | Modelo de caixa (box model) |
| Aula 04 (Bordas) | Estilização de bordas |
| Aula 05 (Margin) | Margens e espaçamento externo |

### Intermediário

Seletores avançados, cascata, herança e unidades de medida.

| Aula | Tema |
|---|---|
| Aula 01 (Classes / ID) | Seletores de classe e ID |
| Aula 02 (Classes - Exercício) | Prática de aplicação de classes |
| Aula 03 (Cascatas) | Ordem de cascata e especificidade |
| Aula 04 (Unidades) | Unidades de medida: `em`/`rem`, porcentagem/pixel, `vw`/`vh` |
| Aula 08 (Imagens) | Estilização de imagens |
| Aula 09 (Seletores) | Seletores CSS avançados |
| Aula 10 (Pseudo-classes) | Pseudo-classes (`:hover`, `:nth-child`, etc.) |
| Aula 11 (Herança) | Herança de propriedades CSS |

### Avançado

Posicionamento, empilhamento e construção de menus de navegação.

| Aula | Tema |
|---|---|
| Aula 01 (Posicionamento) | Propriedade `position` (static, relative, absolute, fixed) |
| Aula 02 (Overflow) | Controle de conteúdo excedente com `overflow` |
| Aula 03 (Z-Index) | Empilhamento de elementos com `z-index` |
| Aula 04 (Flutuantes) | Elementos flutuantes com `float` e `clear` |
| Aula 05 (Nav Vertical) | Construção de menu de navegação vertical |
| Aula 06 (Nav Horizontal) | Construção de menu de navegação horizontal |
| Aula 07 (Tags) | Prática geral com tags e estilização |

### FlexBox

Layout flexível com Flexbox.

| Aula | Tema |
|---|---|
| Aula 01 (Introdução) | Conceitos iniciais do Flexbox |
| Aula 02 (Alinhamentos) | `justify-content`, `align-items`, `align-self`, `flex-basis`, `flex-grow`/`flex-shrink` |

### Grid

Layout em grade com CSS Grid.

| Aula | Tema |
|---|---|
| Aula 01 (Intro) | Introdução ao CSS Grid e definição de colunas |
| Aula 02 | Posicionamento de itens dentro do grid |
| Testes | Exercícios livres de prática com Grid |

## Como visualizar

Clone o repositório:

```bash
git clone https://github.com/oIcaro/aulas-CSS.git
```

Em seguida, abra o arquivo `index.html` (ou o `.html` correspondente) da aula desejada diretamente no navegador.
